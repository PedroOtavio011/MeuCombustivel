# 🚗 Combustível Certo - Ethanol vs Gasoline Calculator

Um aplicativo simples, rápido e intuitivo desenvolvido em **C#** e **.NET MAUI** para ajudar motoristas a economizarem no posto de combustível. O app calcula se compensa mais abastecer com Álcool (Etanol) ou Gasolina com base na famosa relação de eficiência de 70%.

## 📱 Como Funciona?
O cálculo é baseado na premissa de que o rendimento do etanol é, em média, 70% do rendimento da gasolina. 

* Se o resultado for **menor que 0.7**, o **Etanol** compensa mais.
* Se for **maior ou igual a 0.7**, a **Gasolina** compensa mais.

* **.NET MAUI (Multi-platform App UI)** - Para suporte multiplataforma (Android, iOS, Windows).

* Interface limpa e amigável.
